# ==============================================================================
# Installation Notes:
# ==============================================================================
#
# 1. Basic Installation (Minimum requirements):
#    pip install -r requirements.txt
#
# 2. After installing requirements, download NLTK data:
#    python -c "import nltk; nltk.download('stopwords'); nltk.download('punkt'); nltk.download('wordnet'); nltk.download('vader_lexicon')"
#
# 3. Download spaCy English model:
#    python -m spacy download en_core_web_sm
#
# 4. For advanced gradient boosting models:
#    Uncomment the respective lines and run: pip install -r requirements.txt
#
# 5. For BERT/Transformer models (requires GPU for good performance):
#    Uncomment torch, transformers, sentence-transformers
#    Note: This will significantly increase installation size (~2GB+)
#
# 6. For BERTopic (advanced topic modeling):
#    Uncomment bertopic, umap-learn, hdbscan
#
# ==============================================================================
# Compatibility Notes:
# ==============================================================================
#
# - Python 3.8+ required
# - For GPU support with PyTorch, install appropriate CUDA version:
#   pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu118
#
# - For Apple Silicon (M1/M2), some packages may require specific versions
# - Windows users may need Microsoft C++ Build Tools for some packages
#

# transformers: Hugging Face transformers (BERT, RoBERTa, etc.)
# sentence-transformers: Sentence embeddings
